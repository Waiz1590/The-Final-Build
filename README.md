# THE FINAL BUILD

A browser-based pixel-art narrative game built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser. The game uses no build step or backend.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root (same folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the website URL shown in Settings → Pages.

Keep all three files together in the repository root; `index.html` loads the other two by filename.
